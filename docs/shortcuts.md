# keyboard shortcuts

`mod` means `ctrl` on windows/linux and `cmd` on macOS.

| action                             | shortcut                  |
| ---------------------------------- | ------------------------- |
| command palette                    | `mod+k`                   |
| new editor                         | `mod+shift+n`             |
| close active editor                | `mod+shift+w`             |
| copy active editor                 | `mod+shift+c`             |
| compare editors                    | `mod+shift+d`             |
| uppercase / lowercase / title case | `mod+shift+u` / `l` / `t` |
| pretty-print json                  | `mod+shift+j`             |
| toggle light/dark                  | `mod+/`                   |
| focus editor 1–8                   | `alt+1` … `alt+8`         |
| shortcut reference                 | `?` outside an editor     |
| close an overlay                   | `escape`                  |

Native editing shortcuts such as copy, paste, undo, redo, select all, and cut are never overridden. Closing a non-empty editor asks for confirmation.
